# Task 2: Personal Portfolio Website

**Track:** Web Development & Designing  
**Level:** Level 1  
**Project Name:** `WebDev-L1-PersonalPortfolio`  
**Internship:** Oasis Infobyte SIP

---

## 🌟 Overview
A modern, dark-themed personal developer portfolio showcasing technical expertise, shipped projects, background experience, and an interactive contact interface.

---

## ✨ Features Checklist
- [x] **Hero / Profile Section:** Professional title, avatar graphics card, interactive live typing effect, availability status badge, social links.
- [x] **About Me Section:** Clear background narrative, key core engineering competencies, and summary metric cards.
- [x] **Skills Section:** Categorized visual skill meter bars (Frontend, Backend & Databases, Tools & DevOps) with percentage indicators.
- [x] **Projects Section:** Interactive project cards with tech stack tags, descriptions, live demo links, and GitHub repository links.
- [x] **Contact Section:** Full form with live validation and confirmation toast, along with direct contact details.
- [x] **Navigation & UX:** Smooth-scrolling sticky navbar with active section indicators.
- [x] **Responsive Design:** Adaptive layout for mobile, tablet, and widescreen monitors.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Modern CSS variables, CSS Grid, Flexbox, glassmorphism, gradient accents
- **JavaScript (Vanilla):** Dynamic typewriter engine, interactive form handler with toast feedback, scroll spy active menu highlighting

---
