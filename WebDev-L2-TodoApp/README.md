## 🌟 Overview
TaskFlow Pro is a feature-rich, responsive task and workflow manager featuring dual pending and completed workflow pipelines, persistent browser storage via `localStorage`, inline editing, priority categorization, search/filtering, timestamps, and real-time completion tracking.

---

## ✨ Features Checklist
- [x] **Input & Task Creator:** Input field + "+ Add Task" button supporting priority tiers (High, Medium, Low), categories (Work, Personal, Study, Urgent), and due dates.
- [x] **Dual Pipeline Columns:** Newly created tasks appear instantly in the Pending column.
- [x] **Mark Complete Toggle:** Smooth transition from Pending to Completed list with strikethrough animation.
- [x] **Inline Editing:** Edit button enables instant in-place text modification with Save/Cancel keys (`Enter` / `Esc`).
- [x] **Permanent Deletion:** Delete button permanently removes tasks from either list.
- [x] **Live Task Counters & Statistics:** Displays "X pending" and "Y completed" alongside total counts and a dynamic percentage progress bar.
- [x] **(Bonus) Timestamps:** Records creation time and completion time for every item.
- [x] **(Bonus) Persistent Local Storage:** All task states automatically sync with `localStorage` across reloads.
- [x] **Empty State Messaging:** Friendly illustrations and helper text when lists are empty.
- [x] **Search & Category Filters:** Rapid keyword filtering and priority tabs.
