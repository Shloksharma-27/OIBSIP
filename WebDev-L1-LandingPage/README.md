# Task 1: Landing Page — NovaAI Developer Platform

**Track:** Web Development & Designing  
**Level:** Level 1  
**Project Name:** `WebDev-L1-LandingPage`  
**Internship:** Oasis Infobyte SIP

---

## 🌟 Overview
NovaAI is a high-converting, responsive SaaS landing page designed with modern web aesthetics (dark mode, glassmorphism, responsive grid layouts, interactive code preview terminal, and micro-animations).

---

## ✨ Features Checklist
- [x] **Fixed / Sticky Navigation Bar:** Includes brand icon, navigation links (Features, Solutions, Pricing, Testimonials), and call-to-action buttons.
- [x] **Hero Section:** Clear headline, animated subheadline, live preview badge, dual call-to-action buttons, and code synthesis terminal preview.
- [x] **Distinct Content Sections:**
  - Metrics & Performance Counters
  - Feature cards grid (6 unique capabilities with gradient badges)
  - Enterprise Solutions & architecture integration visual
  - Client Testimonials with star ratings and executive profiles
  - Dynamic Pricing Table with Monthly / Annual discount billing toggle
- [x] **Footer:** Multi-column layout with product links, legal links, newsletter, and social handles.
- [x] **Consistent Colour Palette:** Tailored dark mode with neon cyan, indigo, and purple gradient accents.
- [x] **Responsive Layout:** Mobile hamburger menu, flexible CSS Grid & Flexbox layouts tested across mobile, tablet, and desktop viewports.
- [x] **Typography & Hierarchy:** Outfit and Plus Jakarta Sans font pairings with intentional line-heights and margins.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic layout tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, Glassmorphism, animations
- **JavaScript (Vanilla):** Dynamic mobile drawer toggle, live pricing billing switch, sticky scroll header effects

---

## 🚀 How to Run Locally
1. Clone or navigate to the repository directory:
   ```bash
   cd OIBSIP/WebDev-L1-LandingPage
   ```
2. Open `index.html` in any modern web browser (Google Chrome, Firefox, Safari, Edge).
   - Alternatively, use VS Code Live Server or run:
     ```bash
     npx serve .
     ```
